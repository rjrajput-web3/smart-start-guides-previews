# B2B Lead Enrichment — Method Checklist (free preview)

1. Search the public web for LIVE, dated hiring signals on Tier-1
   (USA/UK/Canada/Australia) companies — prefer the company's own careers
   subdomain over job-board scrapes.
2. Pick the strongest candidate: dated posting, fully remote, explicitly
   AI-native or automation-shaped role.
3. Read the primary source IN FULL (the careers page itself) and quote only
   what that page says: role, location, volume targets, application flow,
   disqualifiers.
4. Corroborate company identity on the company homepage + independent
   directory listings (HQ city/state, founding year).
5. Check the named contact honestly: name only who the posting itself
   names. If no hiring-manager name is published, say so — never invent one.
6. Email status: if no public address is published anywhere you read,
   record "Unverified — no public address found". NEVER guess or
   pattern-derive an address (firstname@company.com is not verified).
7. Write the outreach in exactly 3 sentences: observation → problem +
   impact → low-friction CTA. Use only facts from the posting.
8. Re-check the careers URL before acting — a posting live today can close
   at any time.

What "validated" means: a fact was read on a public source named in the
record, with its URL cited. Anything else is marked unverified.
